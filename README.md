## Descripción del proyecto
Esta es una plantilla para proyectos en los que generar una documentación en formato de página web y un blog a modo de cuaderno de bitácora. La documentación y el blog se generan automáticamente a partir de archivos Markdown.

Además se pueden añadir los recursos necesarios para el proyecto, como imágenes, archivos de datos, etc. 

La estructura de carpetas y archivos es la siguiente:

```text
📁 resources
      │
      ├───📁 files
      │        │
      │        ├───📁 audio
      │        ├───📁 imagen
      │        ├───📁 texto      
      │        └───📁 video
      ├───📁 3d-design
      │        │
      │        ├───📁 stl
      │        ├───📁 3mf
      │        └───📁 gcode
      └───📁 source-code
               ├───📁 scripts
               └───📁 configs
```
